# 科研决策记录 · record-research-decisions

一个按需使用的 Codex skill，用来整理研究者在科研协作中作出的判断、批评、取舍和审批，记录它们如何影响 AI 行动、研究步骤或研究方向。记录保存在使用者指定的本地 Markdown 文件中。

它面向需要回顾科研协作过程的人，不只记录最终结论：一次批评针对什么、当时为什么改变方法、哪些理由没有说清、方案是否执行，以及效果是否得到验证，都应分别保留。尚未确定的想法、用户转述的意见与人工批准的方案不会混为一谈。

## 安装

在 Codex 中发送：

```text
使用 $skill-installer，从 https://github.com/KKEERB/record-research-decisions/tree/main/skills/record-research-decisions 安装 skill。安装后告诉我何时可以调用。
```

安装后，在新的 Codex 回合中显式调用 `$record-research-decisions`。也可以将 `skills/record-research-decisions/` 整个目录复制到个人 skill 目录 `~/.agents/skills/`；具体路径与权限取决于使用环境。若未显示，重新打开 Codex 并检查 skill 列表。

## 使用

```text
使用 $record-research-decisions，整理本次对话中我对研究目标、方法和结论边界的判断与修改意见。保留来源、适用范围和未说明的理由，并保存到当前科研项目的 research-decisions.md。
```

也可以指定可访问的历史对话、项目文件或已有记录进行补记。用户明确指定目标文件时优先更新该文件；否则对明确且已授权的本地科研项目，默认使用项目根目录的 `research-decisions.md`。缺失或无法读取的材料会列为缺口，不凭名称推断内容。现有记录保留旧判断，后续补充、撤回或取代会标明关联。

## 每日定时记录

**skill 提供记录方法，不会自行创建定时任务或后台监听。** 要每天运行，需要在支持定时任务的 Codex 桌面环境中另行创建任务。例如：

```text
请在这个 Codex 桌面环境中创建一个每日 21:30（我的本地时区）的定时任务：
使用 $record-research-decisions 检查我指定的科研对话和项目自上次检查以来的新判断，
增量更新我指定的本地 Markdown 记录，注明来源、缺失和无法确认的部分。
同时检查旧对话中新增的消息；不要把缺源或截断内容记为已完整检查。
不上传、分享对话或数据，不把候选判断自动升级为通用规则。
请告诉我任务保存位置、实际状态，并在首次运行后报告覆盖范围和缺口。
```

需要由使用者确定具体时间、授权范围与记录位置。依赖本机文件时，应保持电脑开机、桌面应用运行，并确认任务有相应读写权限。不同环境对历史对话、跨项目文件和定时功能的支持可能不同；首次运行后应核对任务回执。skill 本身不提供跨会话发现器、可靠增量游标或并发锁，也不保证自动去重、完整覆盖或错过后自动补跑。

## 记录原则

- 区分用户直接表达、用户转述、AI 建议与文件记载；没有明说的理由保留为未知。
- 区分讨论、有限批准、实际执行和科学效果，不把历史批准当成本次任务的权限。
- 对相同来源的同一事件尽量去重，保留原事件与后续修改；不同意见及待检验想法可并存。
- 记录范围以实际可读取、用户授权的材料为准；仅有摘要或缓存时说明其局限。
- 默认只保存必要短摘录和来源定位，不自动上传、发布、共享完整对话或研究数据，也不自动形成通用科研规则。
